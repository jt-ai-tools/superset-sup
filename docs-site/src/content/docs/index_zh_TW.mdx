## 為什麼選擇 sup？

- **透過 Superset 的資料存取層執行任何 SQL** - 取得豐富的表格結果
- 備份與還原圖表、儀表板與資料集，具備完整的依賴追蹤
- 使用 Jinja2 範本在 Superset 執行個體間同步資產
- **與 dbt Core/Cloud 雙向強化元數據** - 未來將支援更多整合
- 自動化工作流程並整合至 CI/CD 流水線
- 適合用於自動化腳本與 AI 輔助的資料探索

## 快速範例

```bash
# 設定您的工作區
sup workspace use 123

# 提取您的圖表
sup chart pull --mine

# 執行 SQL 查詢
sup sql "SELECT COUNT(*) FROM users"

# 推送至另一個工作區
sup chart push --workspace-id 456
```
