⚙️ 配置管理

## 配置來源（按優先順序）

- 環境變數：`SUP_*`（最高優先權）
- 全域配置：`~/.sup/config.yml`
- 專案配置：`.sup/state.yml`（目前目錄）


## 關鍵設定

- 身份驗證：API Token、工作區憑證
- 預設值：目前工作區 ID、資料庫 ID、目標工作區
- 偏好設定：輸出格式、資產目錄路徑
- 企業級：跨工作區同步配置


## 快速設定

- **步驟 1**：`sup config auth` - 設定身份驗證憑證
- **步驟 2**：`sup config show` - 驗證目前設定
- **步驟 3**：`sup config env` - 查看所有可用的環境變數


## 常見任務

- **設定工作區**：`sup config set workspace-id 123`
- **設定目標**：`sup config set target-workspace-id 456`
- **資產目錄**：`sup config set assets-folder ./my-assets`

## 使用方式

```bash
sup config [指令] [選項]
```

## 子指令

| 指令 | 說明 |
|---------|-------------|
| `sup config show` | 顯示目前的配置設定 |
| `sup config set` | 設定配置值 |
| `sup config auth` | 設定身份驗證憑證 |
| `sup config init` | 在目前目錄初始化 sup 配置 |
| `sup config env` | 顯示 sup 配置可用的環境變數 |
