管理使用者

## 使用方式

```bash
sup user [指令] [選項]
```

## 子指令

| 指令 | 說明 |
|---------|-------------|
| `sup user list` | 列出目前或指定工作區中的所有使用者 |
| `sup user info` | 顯示使用者的詳細資訊 |
