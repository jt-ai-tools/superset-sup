管理工作區

## 使用方式

```bash
sup workspace [指令] [選項]
```

## 子指令

| 指令 | 說明 |
|---------|-------------|
| `sup workspace list` | 列出所有可用的工作區 |
| `sup workspace use` | 設定目前工作階段的預設工作區 |
| `sup workspace info` | 顯示工作區的詳細資訊 |
| `sup workspace set-target` | 為跨工作區操作設定匯入目標工作區 |
| `sup workspace show` | 顯示目前的工作區上下文，包含來源與匯入目標 |
