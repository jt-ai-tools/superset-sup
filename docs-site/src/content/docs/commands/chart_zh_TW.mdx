管理圖表

## 使用方式

```bash
sup chart [指令] [選項]
```

## 子指令

| 指令 | 說明 |
|---------|-------------|
| `sup chart list` | 列出目前或指定工作區中的圖表 |
| `sup chart info` | 顯示圖表的詳細資訊 |
| `sup chart sql` | 取得驅動圖表的編譯後 SQL 查詢 |
| `sup chart data` | 取得圖表的實際資料結果 |
| `sup chart pull` | 從 Superset 工作區提取圖表定義至本地檔案系統 |
| `sup chart push` | 從本地檔案系統將圖表定義推送至 Superset 工作區 |
