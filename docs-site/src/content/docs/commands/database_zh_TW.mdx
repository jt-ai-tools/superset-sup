管理資料庫

## 使用方式

```bash
sup database [指令] [選項]
```

## 子指令

| 指令 | 說明 |
|---------|-------------|
| `sup database list` | 列出目前或指定工作區中的所有資料庫 |
| `sup database use` | 設定 SQL 查詢的預設資料庫 |
| `sup database info` | 顯示資料庫的詳細資訊 |
