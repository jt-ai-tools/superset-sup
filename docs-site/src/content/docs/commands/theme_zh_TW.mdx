測試主題與顏色

## 使用方式

```bash
sup theme [指令] [選項]
```

## 子指令

| 指令 | 說明 |
|---------|-------------|
| `sup theme colors` | 使用十六進位 (hex) 顏色測試 ASCII 標誌的不同綠色選項，以實現最大區分度 |
| `sup theme palette` | 測試完整調色盤 |
| `sup theme banner` | 使用目前品牌設計測試完整橫幅 (Banner) |
