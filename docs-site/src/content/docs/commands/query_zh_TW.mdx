管理已儲存的查詢

## 使用方式

```bash
sup query [指令] [選項]
```

## 子指令

| 指令 | 說明 |
|---------|-------------|
| `sup query list` | 列出目前或指定工作區中的已儲存查詢 |
| `sup query info` | 顯示已儲存查詢的詳細資訊 |
